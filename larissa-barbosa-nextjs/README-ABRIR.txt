PROJETO LARISSA BARBOSA — COMO ABRIR

1. Extraia a pasta larissa-barbosa-nextjs para um local do computador.
2. Abra essa pasta no Visual Studio Code (a pasta que contém package.json).
3. Abra o Terminal > Novo Terminal.
4. Execute:
   npm install
5. Depois execute:
   npm run dev
6. Abra no navegador:
   http://localhost:3000

IMPORTANTE:
- O vídeo original da página inicial foi preservado em public/videos/hero-video.mp4.
- A foto da seção Sobre está em public/images/larissa-sobre.png.
- Se o comando npm não funcionar, instale uma versão LTS do Node.js e reinicie o VS Code.
